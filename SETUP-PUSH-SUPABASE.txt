Kapan push terkirim:
- Mekanik input Daily Maintenance -> Supervisor
- Supervisor Approve / Reject -> Mekanik pembuat report
- Laporan Breakdown Unit baru -> semua user
- Rencana Jadwal Maintenance / Jadwal Pre Inspection baru -> mekanik PIC

Catatan keamanan: fungsi bisa dipanggil siapa pun yang punya anon key (sama seperti akses database sekarang). Aman untuk pemakaian internal; bila perlu dibatasi, tambahkan token rahasia.
Perangkat yang logout otomatis berhenti menerima push. Langganan kadaluarsa dibersihkan otomatis.
